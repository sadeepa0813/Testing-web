# NuwaraGo — Nuwara Eliya Tourism MVP Demo

Static demo built with:
- HTML
- CSS
- Vanilla JavaScript

Included:
- Responsive landing page
- Stay cards and booking request modal
- 1-day / 2-day tour packages
- Vehicle booking requests
- Places section
- Custom trip planner
- Demo sign-in
- Search interaction
- Mobile responsive layout

## Run
Open `index.html` in a browser.
